title: Contact
description: How to reach Fishhook Studios about Nagma.
---

The simplest way to reach us is email: [hello@nagma.app](mailto:hello@nagma.app).

- **Found a bug?** Open an issue on [GitHub](https://github.com/fish-hook-studios/nagma/issues), with the version and the steps that show it.
- **A security problem?** Please report it privately, as the [security page](/security/) describes.
- **Running a server for a team?** Start with the [self-hosting guide](/docs/self-hosting/).
